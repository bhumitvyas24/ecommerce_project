# Customer Analytics Using SQL

## 📌 Project Overview
An e-commerce analytics project using **PostgreSQL** and the Olist dataset to analyse sales performance, customer behaviour, product categories, customer satisfaction, and delivery operations.

## 🛠️ Tech Stack
- **Database:** PostgreSQL
- **Query Language:** SQL

## 📊 Key Analysis
- Revenue, total orders, and Average Order Value (AOV).
- Customer lifetime value (CLV) and repeat customer analysis.
- Monthly revenue trends, growth rates, and cumulative revenue.
- Top-performing products and product categories.
- Customer review scores and satisfaction.
- Delivery times, late deliveries, and state-wise performance.
- Data quality checks for duplicate records and missing values.

## 🗄️ SQL Implementation
- Analysed nine relational database tables.
- Used joins, CTEs, subqueries, aggregate functions, and window functions.
- Created three SQL views for structured business analysis.
- Performed data quality validation using record counts, duplicate checks, and NULL checks.

## 🎯 Key Skills
SQL | PostgreSQL | Data Analysis | Customer Analytics | Business Intelligence

## 📝 Conclusion
This project demonstrates the use of SQL to transform raw e-commerce data into meaningful business insights, supporting data-driven decision-making across sales, customer behaviour, and operational performance.
